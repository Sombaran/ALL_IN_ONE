mobile_agent |Build Status|
============================

Description:
------------

With this Module:
- This module provides all the required APIS for mobile APPlication
- login API: for registration. 
- set_cap API: for set the cap mode to change the SSID and password.

Dependencies:
-------------
Install all the requirements using
``pip install flask``

How to use:
-----------
.. code:: python
   ``python mobile_agent.py ``
