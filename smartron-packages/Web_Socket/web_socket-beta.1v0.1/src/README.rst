web_socket |Build Status|
============================

Description:
------------

With this Module:
- This module provides all the requirements for IOT.
- Support tronX cloud and zigbee and zwave integration,
- Integrate zigbee and zwave data to tronX cloud.

Dependencies:
-------------
Install all the requirements using
``pip install socketIO_client``

How to use:
-----------
.. code:: python
   ``python web_socket.py ``
