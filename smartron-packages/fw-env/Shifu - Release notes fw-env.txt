Release note identifier ([fw-env], date:28-02-2018 , version 0.1)
-----------------------------------------------------------

Features and changes (new features, defects corrected, caveats etc): 
- This package gives access to firmware environment variables for c programs.
- It has three API's. ie.,remove_char_from_string, get_fw_env, set_fw_env. Included in header file.
- Should not to pass NULL value to functions
