-------------------------
Readme for BT Python APIs
-------------------------
docs: This folder includes all documents related to Python_BT package
Python_BT: This folder includes source code for Python_BT package
tests: This folder contains the test programs 
changelog: This file captures the changes done since the first version
LICENCE: This file captures the licensing information for Python_BT package
Makefile: Main makefile responsible for building Python_BT package
Python_BT.cpp: C++ source responsible for building the Python_BT package
requirements.txt: Pre-requisites for using Python_BT package
setup.py: Installs all the dependencies from the requirements.txt

To integrate the Python APIs for BT in OpenWRT build environment, enable the folowing configuration in make menuconfig: 

Network->Python_BT
