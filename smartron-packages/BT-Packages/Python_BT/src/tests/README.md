-------------------------------------
Readme for sample codes for API calls
-------------------------------------

1. Scan_BT.py- discovers available devices
2. Connect_BT.py- pairs and connects to particular device
3. Paired_list_BT.py- shows the list of paired devices
4. Connected_device_list_BT.py- shows the list of connected devices
5. Disconnect_BT.py- disconnects a connected Bt device
6. Unpair_BT.py- unpairs a connected BT device
7. AVRCP_BT.py- AVRCP functionality for remote audio controls
8. Discoverable_BT.py - Discoverable time and discoverable mode setting
9. Adapter_name_BT.py - Setting BT adapter custom name.


To run the programs, use:

Change the config.py for mac_addr of remote device, PINAME to change adapter name and run
python <Sample_PROGRAM>
