# UML Design Concepts

> This diagram illustrates various UML design concepts including composition, aggregation, direct association, dependency, generalization, and realization. There are six different types of relationships depicted between classes, each with a brief explanation.
> UML is linked with object-oriented design and analysis. UML makes use of elements and forms associations between them to form diagrams. Diagrams in UML can be broadly classified as: 
[Click here](https://github.com/Sombaran/ALL_IN_ONE/blob/main/2025_practice/umlDesign/README.png)
- Structural Diagrams: These diagrams represent the static aspects of a system. They include Class Diagrams, Object Diagrams, Component Diagrams, Deployment Diagrams, Package Diagrams, and Composite Structure Diagrams.
- Behavioral Diagrams: These diagrams represent the dynamic aspects of a system. They include Use Case Diagrams, Sequence Diagrams, Activity Diagrams, State Machine Diagrams, Communication Diagrams, Interaction Overview Diagrams, and Timing Diagrams.
